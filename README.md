# User Profile Checker using Python

This Python program checks whether a user's profile details are valid or not.

The following inputs are taken from the user:
- Full Name
- Email Address
- Mobile Number
- Age

## Validation Rules

Full Name:
- Must contain at least one space (first and last name)
- Should not start or end with a space

Email Address:
- Must include '@' symbol
- Must include '.' symbol
- Should not begin with '@'

Mobile Number:
- Must be exactly 10 digits
- Must contain only numbers
- Should not start with zero

Age:
- Must be greater than 18 and less than or equal to 60

## Program Output

If all conditions are satisfied:
User Profile is VALID

Otherwise:
User Profile is INVALID

## Purpose

This program demonstrates basic input handling and conditional validation in Python.
